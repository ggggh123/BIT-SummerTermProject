核心系统与写入边界

实线为核心调用；虚线为模拟器遥测入口。

Qt 用户端

登录/自动注册、找站查桩、预约、开始与停止充电、结算。

含腾讯地图驾车/步行导航
↔长度前缀 JSON / TCP

Qt 管理 / 服务端

业务校验、订单状态机、管理统计与串行事务；唯一运行时 SQLite writer。

核心写入权威
所有运行时数据变更都经 Qt 管理 / 服务端串行事务落库

Qt 模拟器

发送电桩状态、功率、电量增量与故障事件；不直接写运行时数据库。

遥测 / 故障事件 → 服务端

SQLite / 黄金库

受校验种子数据、用户余额、订单、站点与电桩状态的可信起点与持久化结果。

服务端唯一写入 · 可审计
