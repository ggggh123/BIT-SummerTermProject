## 3. 数据真实性与异常处理

1. 页头分开显示“接口连接状态”和“批次时间”；页脚说明项目模拟数据与离线数仓口径。
2. 缺失坐标保留为 null：不落到 `(0, 0)`，不补造位置；站点选择和其他经营统计仍保留该站。
3. 预测标识读取批次 `isBaseline`、`modelVersion`，区分 ML、基线和来源未标明。没有预测的站点只画实际曲线。
4. 仅预测接口的 `4041` 作为“暂无预测”降级；网络失败或其他接口错误仍显示异常，保留上一次成功数据。一路请求成功不会遮掉另一路失败。
5. 图表主题只改显示，不修改统计值；事件文本、地图提示中的动态文本做转义。
6. 平均等待为 0 是队友新批次中已确认的数据特征：预约与开始时间相同。不能再把它描述为未修复 SQL 缺陷，也未为展示效果生成虚构等待时间。

### 用户验收后的环形图修复

首页“充电桩状态分布”的图表高度为 147px。原实现把数字放在图高 42% 处，再把“总量”固定向下偏移 32px，导致下行文字伸入圆环、被遮挡。

修复为同一个富文本块，与圆环共用圆心 `[29%, 48%]`，按文字块整体垂直居中；数值/副标题行高分别为 28/14px，并明确文本层级，保持同一主题和业务数据不变。首页 1920×1080、1366×768，以及站点快慢充图、企业 RFM 图均进行了浏览器目视复查。新增测试覆盖 0、36、251、287、4985 等总量，防止恢复为分离偏移的定位方式。
