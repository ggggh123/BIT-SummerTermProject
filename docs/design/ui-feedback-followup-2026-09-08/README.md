## 二、服务端设备概览底色

问题原因：系统健康卡片中的 `healthDetailsViews` 是嵌套的 `QStackedWidget`，套用了页面级深色背景 `#102536`，与卡片背景 `#193444` 不一致，形成深色矩形。

修复为仅对这个嵌套容器设置透明背景，使设备统计、分布条和说明文字共享外层卡片底色。不改全局页面底色，保留「设备状态概览／诊断明细」切换和故障定位功能。

加入像素回归检查：1360×860、1280×720 下，嵌套容器内部空白点的渲染颜色必须等于外层卡片内部颜色，而不只检查样式字符串。

截图：[1360×860](health-background-1360x860.png)、[1280×720](health-background-1280x720.png)。较小桌面窗口下继续使用原有纵向滚动区域。

## 三、我的账户：冻结／解冻状态

- 在头像与账户余额之间显示「账号正常／账号已冻结」状态标签和「刷新状态」按钮。
- 冻结时展示醒目的暖珊瑚色提示卡，明确说明：暂不可预约、开始充电或充值；已有订单仍可取消预约、停止充电和结算，资料与用电记录可查看；解除冻结需联系管理员。
- 冻结状态下禁用充值输入与充值按钮，不误禁昵称修改、账号管理或历史记录。业务许可仍以服务端为准，客户端没有绕过或修改冻结规则。
- 读取现有 `user.get` 的 `status` 字段。进入账户页会刷新；页面可见且空闲、已连接时每 5 秒自动同步，手动点击「刷新状态」也能立即查询。不需要退出再登录才能显示冻结或解冻。
- 编辑输入、账户写请求或待对账期间暂停自动查询；只读请求单飞，隐藏账户页和断线时不轮询。
- 自动更新不覆盖未保存的昵称，也不清掉刚出现的充值输入错误。断线不把已冻结状态改成正常；退出后清空账号数据，旧会话的迟到回包不能恢复旧账户信息。

截图：[冻结账号 390×720](account-frozen-390x720.png)、[冻结账号 390×844](account-frozen-390x844.png)。

3. 预约空闲充电桩，检查成功图标与按钮；进入服务端「系统健康」检查设备概览底色。

注意：一键启动新轮次会复制黄金数据，不延续上一轮业务状态；旧轮次数据库与日志仍留档。正在运行的旧程序不会因后台编译自动更新。
