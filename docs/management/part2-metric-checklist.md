# 第二阶段大屏数值抽验表（模板）

> 维护人：#1 王浩恩（PM）｜日期：2026-09-14
> 依据：`Part2/01-PM-Web可视化大屏设计.md` §7 验收第 3 条——「大屏数值与 ADS 表抽验一致（与 #3 共同抽查至少 10 个指标）」
> 用法：ADS 产出后，逐行从 ADS 表取真值，与大屏页面显示值对照；不一致则记入缺陷清单并定位（数据问题 / 接口问题 / 展示问题）。

## 抽验方法

1. 从 HDFS 或 `ads.db` 直接查 ADS 表（示例：`hdfs dfs -cat /ev-charging/ads/ads_revenue_overview/*.csv | head`）。
2. 打开大屏对应页面，读取显示值（金额是元，注意 ADS 存的是整数分，需 ÷100 再比）。
3. 差异为 0 记「一致」；否则记录差异值与原因分类。
4. 抽验人与复核人分别签字；本表随答辩材料归档。

## 差异原因分类（填写用）

| 分类 | 含义 | 处理 |
|---|---|---|
| A 数据 | ADS 表本身算错或口径与文档不一致 | 退回 #4 修 SQL |
| B 接口 | Flask 读 ADS 时换算错（分/元、百分比、时区） | 退回 #2 修 API |
| C 展示 | 前端换算或聚合错 | #1 自行修复 |
| D 口径 | 文档未定义清楚导致两边理解不同 | 补文档后重验 |
