## 4. 答辩时段登记（`DEMO_FORECAST_ORIGIN` 输入）

**已冻结（2026-09-02 组长确认）：演示的“模拟现在” = `2026-09-01T09:00:00+08:00`（9/1 上午 9 点）。**

- 口径：管理端、模拟器、大屏、ML 预测窗口全部按该模拟时间演示。模拟器默认 `startTime` 与数据 seed `--cutoff` 本就是 `2026-09-01T09:00:00+08:00`（`data-simulator.md` Task 2/7），`DEMO_FORECAST_ORIGIN` 由候选转正为该值，全组一致。
- 覆盖性：ML 24 小时预测窗口自 9/1 09:00 起，完整覆盖演示时段；无需再为真实答辩钟点重建数据。
- **答辩稿必须显式写明**：“演示时间为模拟时间 2026-09-01 09:00，非真实系统日期（9/10）”，避免评委以真实日期理解数据（#1 负责，写入 PPT/演示稿）。
- 9/10 现场答辩的具体钟点：待课程确认后在此补充，仅影响彩排排程，不再影响数据工件。
- 约束：9/9 代码冻结前，任何数据重建必须保持同一 `DEMO_FORECAST_ORIGIN=2026-09-01T09:00:00+08:00`，不得改用真实时钟。
