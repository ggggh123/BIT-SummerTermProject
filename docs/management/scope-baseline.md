## 3. 合法预测降级语义

- 服务端返回无 active forecast 是合法核心响应。
- 用户端收到 `forecastRun: null` 与 `records: []` 时显示“暂无预测”；找站、导航、预约和充电链路继续可用。
- 核心黄金库可保留静态 last-good 预测，也可在基础 profile 中没有 active forecast。
- Web snapshot 和在线 `forecast.publish` 都不是核心启动、核心 smoke、核心彩排或 release gate 的前置条件。

## 4. 核心 Definition of Done

从受校验的黄金数据开始，在**同一提交**上连续两次完成：登录/自动注册 → 查站与查桩 → 腾讯地图驾车或步行导航 → 预约 → 开始充电 → 模拟器遥测或故障事件 → 停止 → 结算 → 用户余额、订单和管理统计一致。两次彩排均不得人工直接修改运行时数据库，不得崩溃或出现无法解释的数据矛盾，并且开放 P0 缺陷必须为零。

## 5. 范围外纪律

- Web/ML 可以单独测试和演示，但不得被隐式加入顶层默认构建图、核心环境检查、核心 smoke 或核心 release gate。
- 任何未来重新启用 Web/ML 的工作必须使用显式 optional profile，并经新的范围决定登记；不得悄悄恢复成硬依赖。
- 原始 `references/` 附件保持只读；范围调整不篡改原始需求。
