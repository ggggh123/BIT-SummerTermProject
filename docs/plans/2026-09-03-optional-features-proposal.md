## 4. 与既有计划的衔接

- 本提案不修改七份实施计划的任何任务，仅在其后追加可选项。
- F3 与 `data-simulator` 计划共用 `database/` 代码路径，F4 共用 `simulator/` 路径：实现时先完成计划内任务（含 Integration Task 1 运维脚本）再扩展。

- F2 依赖的预测数据出口待 ML 重建后由 #5 对齐，界面与计算逻辑可先用占位数据开发。
- F4 的展示端联动（事件流/曲线同步）方向保留，落地时机取决于 Web 重建进度。
- 所有 P1 项与 Integration 计划的冒烟、一致性检查不冲突：F5 新增动作不进入冒烟调用清单，无需调整检查工具。
