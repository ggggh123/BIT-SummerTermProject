## 3. 队友从独立 clone 启动

默认环境为 **Ubuntu 22.04 x86_64 / APT Qt 6.2 / GCC 11 / CMake 3.22 / C++17**。依赖安装到系统，不使用虚拟环境或临时 Qt 安装。先按[团队开发指南](../development/ubuntu22.md)切换到本次 PR 分支；合入后统一使用 `dev`。不要拷贝他人的 build 目录。

在 clone 根目录执行：

```bash
python3 scripts/quickstart.py --start
```

默认按需安装全局依赖、检查环境、使用 Ninja 增量编译三个程序，并行数 2，然后从受校验黄金库创建新轮次、启动三端。低内存虚拟机可改为：

```bash
python3 scripts/quickstart.py --start --jobs 1
```

启动脚本会输出本轮 run ID 和停止命令；结束后使用相应 run ID 停止，不用按进程名广泛杀程序。每次新轮次保留上一轮数据库与日志，但不延续上一轮订单和余额。

如需分步构建、手动冷启动、在线复位或现场展示，见[演示操作手册](core-demo-runbook.md)。本机外层目录的「一键启动新版 UI」固定路径包装仍可继续使用，但不是跨机器部署入口，不放入团队源码默认路径。
