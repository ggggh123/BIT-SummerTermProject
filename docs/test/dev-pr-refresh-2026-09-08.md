## PR 自动审查反馈复核

1. **自定义模拟器 token 不 trim：保留设计。** 配置的 token 按原值精确匹配，并固定于启动快照。已有 `configuredSimulatorTokenDoesNotRotateWithEnvironment` 明确断言带额外空格的请求不通过；把此处改成自动 trim 会改变已验证语义。默认开发别名的兼容归一化不等于自定义 token 也必须归一化。
