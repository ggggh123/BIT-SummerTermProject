## 核验要点

- 登录输入、提交中防重复点击、错误可见性、连接提示。
- 390×720 与 390×844 逻辑尺寸下保持可读；底部导航不被长页面挤出窗口。
- 找站列表与站点详情分开，返回可看到已有列表。
- 空闲数为零的站点仍能打开详情；忙碌/故障电桩的资料可读，只有选择动作禁用。
- 选择空闲电桩仍进入已有预约确认，不提前执行预约或开始充电。

## 本轮明确的实施取舍

1. 未提交工作通过工作区快照进行独立审查，保留本地审查记录；后续集成仍需正式提交。
2. 初始高度遵循屏幕可用高度减64px并以844px封顶，不强制480px下限，避免小屏装饰挤出；极小屏幕需更多滚动。

5. 暂缓登录插画轻微底色边界的进一步修饰：保留完整独立位图与已通过的布局；最终审查确认其为P3。若影响用户最终展示预期，后续仍需做素材/背景衔接精修。
