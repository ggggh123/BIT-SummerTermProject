# Qt 用户端第二批 UI 精修记录

日期：2026-09-06。基于 `feat/runtime-delivery-20260906` 分支的 `ad44b57` 继续实施；本记录随本批 UI 代码与截图一并提交。用户已授权推送工作分支，`dev` / `main` 的集成状态以远端合并记录为准。

## 目标与边界

用户确认展示效果是重点，继续已批准的原生 Qt、青绿主题、390×720 / 390×844 手机式交互，不另换风格。本批补齐账户、历史订单与导航外壳，保留既有登录、找站、站点详情、充电和结算设计。

不修改服务协议、服务器、数据库或需求矩阵；不增加 Web 大屏或机器学习功能。不安装开发环境，不使用真实腾讯 Key、不运行在线地图冒烟。Superdesign 授权页出现异常后，按用户“先继续”的指示，直接复用本地已确认主题与已有素材；没有新建云端设计或消耗生图额度。

## 实际改动

### 我的账户

- 绿色头像、昵称和手机号构成身份区；突出账户余额。
- 充值与账户资料使用独立白色卡片；充值继续明确标注“项目演示充值，不涉及真实支付”。
- 默认头像复用已有 Material 图标，以目标尺寸和屏幕比例渲染，避免小位图放大模糊；用户已有头像仍正常加载。
- 没有错误时收起错误行，发生错误时保留具体原因和原有重试/对账保护；不提前修改服务端余额。
- 保留昵称和充值的防重复提交、断线结果未确认、权威对账与会话失效逻辑；补齐手机号无障碍名称。

### 历史订单

- 保留 `QListWidget` 数据、精确分页、排序、缓存和代际机制，逐条渲染订单卡片。
- 独立呈现订单编号、状态、站点、充电桩、金额、用电量、预约/开始/结束时间。
- 界面时间显示北京时间至整秒；原始时区、小数秒等完整字符串保存在悬停提示和列表可访问文本中，不改变排序或协议值。
- 明确区分加载中、首页无记录、非首页空页、读取失败、离线无缓存和离线有缓存；非首页即使为空也可返回上一页。
- 长站名、长桩编号按当前列表宽度换行；列表保留键盘滚动与可见焦点。

### 导航与公共布局

- 导航页统一返回图标、标题、目的地摘要、出行方式、重试与地图提示样式；保留腾讯 QWebEngine/JavaScript 接口及已有路线状态机。
- 较长的故障提示不再把390px窗口撑宽；保留失败提示、上次成功路线和返回操作。
- 返回图标补齐可见的键盘焦点。
- 修正页面栈的 `heightForWidth`：只依据当前页测量，避免已隐藏的长账户页继续撑高历史页，遮挡分页按钮。

## 测试过程中发现并修正的问题

1. 原页面的空错误行、历史空白列表和导航长提示撑宽分别由新增回归用例先复现，再实施修复；导航宽度初始实际为774px，目标390px。
2. 新增测试的充值响应起初误用完整 user 对象；按既有协议改为 `userId + balanceFen`，没有放宽生产解析器。
3. 测试起初没有等待登录订单校验、空列表响应处理完成，截图等待偶然掩盖了竞态；改为等待真实页面状态和刷新按钮解除pending，正常无截图执行同样有效。
4. 截图复查发现历史分页部分被底栏遮挡；将“与视口相交”提高为“完整位于视口”，先复现长文本720场景，再修正页面栈测量。
5. 完整回归首轮31/32通过，唯一失败是既有历史离线颜色断言；保留本地危险色 `#BE4B42`，不删除原缓存或离线业务断言。
6. 独立审查指出非首页空态回退、导航返回焦点、列表焦点和手机号名称四项问题；均补充针对性回归，先看到失败再修复。
