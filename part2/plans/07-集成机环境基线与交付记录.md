## 7. 日常运维

### 7.1 Hadoop 启停（虚拟机重启后必须手动执行）

```bash
sudo -u hadoop bash -lc "start-dfs.sh && start-yarn.sh"   # 启动
sudo -u hadoop bash -lc "jps"                             # 确认 5 个进程
sudo -u hadoop bash -lc "stop-yarn.sh && stop-dfs.sh"     # 关机前优雅停止
```

### 7.2 Flask 启停

```bash
cd ~/part2/server
setsid nohup python3 app.py > /tmp/flask.log 2>&1 < /dev/null &   # 启动
pkill -f "python3 app.py"                                          # 停止
curl -s http://127.0.0.1:5000/api/health                           # 探活
```


### 7.4 网络与 IP

- 当前为 VMware NAT，Windows 宿主可直接访问；若需**其他成员机**访问，需改为桥接模式。
